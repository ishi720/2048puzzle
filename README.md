# 2048 Puzzle Game

4x4グリッド上でタイルをスライドさせ、同じ数字を合体させて2048を目指すパズルゲームです。

<img width="1200" height="800" alt="2048puzzle" src="https://github.com/user-attachments/assets/88217001-51fc-4ca7-8d36-ba280462ba18" />


## 遊び方

1. **矢印キー** または **スワイプ** でタイルを動かします
2. 同じ数字がぶつかると合体して2倍になります
3. 動かすたびに新しいタイル（2 または 4）が出現します
4. 2048を作ることを目指しましょう
5. 動かせなくなったらゲームオーバーです

## 機能

- キーボード操作（矢印キー）
- タッチ/スワイプ操作（モバイル対応）
- スムーズなタイルアニメーション
- レスポンシブデザイン
- スコア表示
- ルール表示ポップアップ
- ゲームリセット機能

## 技術スタック

- **React** 19
- **Vite** 7
- **p5.js** - ゲーム描画
- **Tailwind CSS** 4

## 開発環境のセットアップ

### 必要な環境

- Node.js 18以上

### インストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

### ビルド

```bash
npm run build
```

ビルド成果物は `dist` フォルダに出力されます。
